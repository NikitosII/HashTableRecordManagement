## Описание

Проект представляет собой консольное приложение на C++, которое позволяет пользователю управлять записями. Каждая запись содержит ФИО, номер договора и дату. Программа поддерживает добавление, поиск, удаление и вывод записей, а также поиск по фрагменту. Поддерживается загрузка данных из файла и сохранение данных в файл.

## Функциональность

- **Добавление записи**: Пользователь может добавить запись, указав ФИО, номер договора и дату.
- **Поиск записи**: Пользователь может искать запись по номеру договора.
- **Удаление записи**: Пользователь может удалить запись по номеру договора.
- **Вывод всех записей**: Пользователь может вывести все записи.
- **Поиск по фрагменту даты**: Пользователь может искать записи по фрагменту даты.
- **Загрузка данных из файла**: Пользователь может загрузить данные из файла.
- **Сохранение данных в файл**: Пользователь может сохранить данные в файл.

## Использование

1. Склонируйте репозиторий:
    ```sh
    git clone <URL репозитория>
    ```
2. Перейдите в директорию проекта:
    ```sh
    cd <имя директории проекта>
    ```
3. Скомпилируйте проект:
    ```sh
    g++ -o HashTableRecordManagement HashTableRecordManagement.cpp HashM.cpp Node.cpp
    ```
4. Запустите программу, указав путь к файлу с данными:
    ```sh
    ./HashTableRecordManagement <путь к файлу>
    ```
    Например:
    ```sh
    ./HashTableRecordManagement data.txt
    ```
    
### Пример использования

1. Скомпилируйте и запустите программу:
    ```sh
    g++ -o HashTableRecordManagement HashTableRecordManagement.cpp HashM.cpp Node.cpp
    ./HashTableRecordManagement data.txt
    ```
2. Следуйте инструкциям в меню:
    ```
    •1 Добавление записи
    •2 Поиск
    •3 Удаление записи
    •4 Просмотр всех имеющихся записей
    •5 Поиск по фрагменту
    •6 Сохранить данные в файл
    •7 Загрузить данные из файла
    •0 Выход
    Введите номер пункта(0-7):
    ```
3. Добавьте запись из файла:
    ```
    Введите номер пункта(0-7): 1
    •1 Добавить запись из файла
    •2 Добавить запись через консоль
    Введите номер пункта(1-2): 1
    ```
4. Добавьте запись через консоль:
    ```
    Введите номер пункта(0-7): 1
    •1 Добавить запись из файла
    •2 Добавить запись через консоль
    Введите номер пункта(1-2): 2
    Enter ФИО: Ivanov.I.I.
    Enter номер договора (из 5 цифр): 14785
    Enter др (дд.мм.гггг): 15.10.2015
    ```
5. Найдите запись по номеру договора:
    ```
    Введите номер пункта(0-7): 2
    Введите данные для поиска: 14785
    Результат: Ivanov.I.I.
    ```
6. Удалите запись по номеру договора:
    ```
    Введите номер пункта(0-7): 3
    Введите данные для удаления (номер договора): 14785
    ```
7. Выведите все записи:
    ```
    Введите номер пункта(0-7): 4
    Sidorov.S.A. - 67890 - 02.02.2021
    Petrov.P.Q. - 23456 - 05.05.2024
    NoName - 12345 - 12.12.2020
    ```
8. Поиск по фрагменту даты:
    ```
    Введите номер пункта(0-7): 5
    Введите фрагмент даты: 05.05
    Найденные записи:
    Petrov.P.Q.
    ```
9. Сохраните данные в файл:
    ```
    Введите номер пункта(0-7): 6
    Данные сохранены в файл: data.txt
    ```

## Алгоритм поиска по фрагменту Кнута-Морриса-Пратта (KMP)

Алгоритм Кнута-Морриса-Пратта (KMP) — это алгоритм для поиска подстрок в строке. Он использует префиксную функцию для ускорения процесса поиска. Основные шаги алгоритма:

1. **Префиксная функция**: Вычисляется для шаблона (подстроки, которую мы ищем). Префиксная функция — это массив, который хранит длину наибольшего суффикса подстроки, который также является префиксом этой подстроки.
2. **Поиск**: Используя префиксную функцию, алгоритм проходит по тексту и сравнивает символы текста с символами шаблона. Если символы совпадают, алгоритм перемещается к следующему символу. Если символы не совпадают, алгоритм использует префиксную функцию для перемещения к следующему возможному совпадению.
3. **Возврат к началу**: Если весь шаблон совпал, алгоритм возвращается к началу шаблона для поиска следующего вхождения.

## Структура проекта

- `Node.h`: Определение структуры `Item`, представляющей запись.

- `main.cpp`: Основной файл программы.
